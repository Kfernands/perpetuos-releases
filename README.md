# PERPETUOS

Ficha automática de D&D 5e com roleta caça-níquel e interface de terminal CRT.

## Como instalar

1. Abra a [última versão](https://github.com/Kfernands/perpetuos-releases/releases/latest).
2. Em **Assets**, baixe o arquivo **`PERPETUOS_x.y.z_x64-setup.exe`**.
3. Execute. Se o Windows mostrar *"O Windows protegeu o computador"*, clique em **Mais informações → Executar assim mesmo**.

Não precisa instalar mais nada. Funciona no Windows 10 e 11.

## Atualizações

Ao abrir, o PERPETUOS verifica se há versão nova e pergunta se você quer atualizar. Suas fichas, campanhas e imagens são mantidas.

## Backup

Os dados ficam no seu computador. Para guardar uma cópia, use **exportar** na tela INÍCIO. Ao desinstalar, **não** marque a opção de apagar os dados do aplicativo se quiser mantê-los.
